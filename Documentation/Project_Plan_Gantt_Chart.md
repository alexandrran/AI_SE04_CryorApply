# Project Plan with Milestones using Gantt Chart

## Project Title
AI_SE04_CryorApply

## Project Overview
CryorApply is an AI-based CV reviewer for students and beginner job seekers. The system allows users to upload a CV, analyse it with AI, and receive feedback about CV structure, skills, experience, formatting, and possible improvements.

The progress presentation on 30 May 2026 is an intermediate presentation. The team will show the current project progress, including documentation, GitHub structure, workflow diagram, system design, and early development plan.

The final version of the project is planned for the beginning of July 2026.
